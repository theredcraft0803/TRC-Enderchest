# TRC: Enderchest

A simple and lightweight PaperMC plugin that adds the `/ec` and `/enderchest` commands, allowing players to quickly access their Ender Chest.

Administrators with the appropriate permission can also use `/ec <player>` to view and manage another player's Ender Chest.

## Versions

Select the desired source code version from the **Branches** menu, or download a pre-built release from one of the following platforms:

* **Modrinth:** *https://modrinth.com/plugin/trc-enderchest*
* **CurseForge:** *https://www.curseforge.com/minecraft/bukkit-plugins/trc-enderchest*
